# Tumar Office

Маркетинговая стратегия Tumar Family Office · Галия Багдат.

- `prd.md` — техзадание и стратегия: цели, план по неделям и кварталам, контент-план, Forbes, LinkedIn, сайт Галии.
- `index.html` — дашборд стратегии (вкладки: Обзор, Неделя, Стратегия, План года, Контент, Forbes и LinkedIn).
- `tg-posts.json` — готовые посты Telegram на первый месяц.

Рабочая версия дашборда с синхронизацией отметок между устройствами открывается в claude.ai. Если открыть `index.html` отдельно, отметки сохраняются только в этом браузере.
